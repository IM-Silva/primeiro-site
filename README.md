# 🦸‍♀️ Site Mulher-Maravilha

Projeto desenvolvido com **HTML e CSS** inspirado na personagem **Mulher-Maravilha**.

## 📖 Sobre o projeto

Site com várias páginas interativas, trazendo informações, imagens e conteúdo visual sobre o filme/personagem.

## 📂 Páginas

- 🏠 Home  
- ⭐ Curiosidades  
- 🖼️ Galeria de Fotos  
- 📞 Contato  

## 💻 Tecnologias utilizadas

- HTML5  
- CSS3  

## ✨ Recursos

- 📱 Layout responsivo  
- 🧭 Menu de navegação  
- 🎬 Trailer em vídeo  
- 🖼️ Galeria de imagens  
- 📩 Formulário de contato
